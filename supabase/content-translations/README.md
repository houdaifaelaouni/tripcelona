# Content translations (2026-11-13)

One SQL file per language (en, fr, ca, it) with the translated tour, FAQ, blog and page text,
generated from the Spanish content exported from production. Not migrations: run each file once
by hand in the Supabase SQL editor, after `20261113000200_content_translations.sql`. Running a file
again is safe (it updates in place). Legal pages are machine translations and should be reviewed.
